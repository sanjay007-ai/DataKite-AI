# API

- `POST /upload` — upload 1–10 supported files using multipart field `files` (also accepts `file`).
- `POST /ask` — ask a natural-language business question.
- `GET /excel/download` — generate the current premium Excel dashboard.

- `GET /charts/download` — chart ZIP.
- `GET /data/download` — current normalized data CSV.
- Existing PDF/Word/PowerPoint report and conversion routes remain available.
