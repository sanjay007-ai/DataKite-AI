# DataKite AI Website — Start

The final release now includes a responsive DataKite AI website designed for desktop/laptop and mobile browsers.

## User flow
1. Open the app.
2. Upload 1–10 business files.
3. DataKite reads the files and creates the analysis context.
4. Dashboard shows detected KPIs and universal charts.
5. Ask DataKite questions in the AI workspace.
6. Use Export Center for Excel, PDF, Word, PowerPoint, CSV.

## Run locally
Windows: run `START_HERE_Windows.bat`.
Then open the address printed by the server (normally `http://127.0.0.1:5000`).

## Phone
After deployment over HTTPS, the PWA can be installed from a supported mobile browser using the browser's install/add-to-home-screen action.
